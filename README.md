Установка
---------------------------
```
sudo npm install -g tree-sitter-cli
```

Хоткей
---------------------------
Открыть неотрии (папки)
```
пробел + e

```
пробел + t
```

```
gd
gD
gr
K
```
вернуться к файлу
```
crtl + o
